# Unparalleled Consulting v2

![License: MIT](https://img.shields.io/badge/License-MIT-green.svg) ![Next.js](https://img.shields.io/badge/Next.js-16-black) ![React](https://img.shields.io/badge/React-19-61dafb) ![Tailwind CSS](https://img.shields.io/badge/Tailwind-4-38bdf8) ![TypeScript](https://img.shields.io/badge/TypeScript-5-3178c6)

Marketing website for Unparalleled Consulting & Management LLC, a bookkeeping, business consulting, and speaking practice. Built with the Next.js App Router, it includes pages for services, about, blog, careers, FAQ, contact, privacy and terms, with a Calendly booking widget, scroll animations, and SEO metadata (sitemap, robots, JSON-LD).

## Getting started

```bash
npm install
npm run dev     # http://localhost:3000
npm run build
npm start
npm run lint
```

## Structure

- `src/app/` - routes (pages, layout, sitemap, robots)
- `src/components/` - Navbar, Footer, ContactForm, FAQAccordion, Calendly components, ScrollReveal
- `public/` - images and web manifest
